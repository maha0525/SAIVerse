## 実機検証の旅 (intent §10 — 完了の定義)

バックエンド再起動だけで入る (フロント変更なし)。**再起動後の最初の送信は全ペルソナのキャッシュが一回割れる** (head から部屋描画が消えた移行コスト、予告済み・一回きり)。

1. 部屋を往復 → 帰還の知覚が「変わっていません」一行
2. アイテムを閉じる → 「(閉じられた)」一行 (本文再掲なし)
3. 新しい絵 (開いた画像アイテム) → 文章と一緒に**絵が見える**
4. 記憶の整理の後、開き直った部屋で**絵が戻る**
5. 滞在中に置かれたアイテムが中身つきで届く (旧「追加されました」ラベルは退役)
6. 起動直後の会話で部屋が見えている (ブートストラップ)
