## 1. 持ち越しの再検証 (8/25 の修理)

Memory 窓 → Chronicle → 「生成」。**一押しで採取から畳みまで通って完了メッセージが出る**こと。「見送りました」は原則もう出ない。

⚠️ **今日の U 変更で確認窓の文言が変わっている**: 畳める材料 (機構文の圧縮後で数えた字数) が U=10,000 に達するまで「あと約 N 文字の会話がたまれば畳めます」と出て、ボタンが押せない。これは**正しい挙動** — エリスの現状は生の超過はあっても材料が薄い可能性があり、その場合は少し会話してから。

## 2. 編纂材料の一本化 (§2-9) と U 級

会話がある程度たまってから「生成」を実行し、新しくできた一次あらすじを見る:

- [ ] スペルを使った期間のあらすじに、**スペルの痕跡が入っている** (500 字以下の結果はそのまま材料に、超えたものは「[Spell Result: ◯◯] を受け取った (N 字)」の一行として要約に織り込まれる)。
- [ ] あらすじ本文の末尾に「（この期間に届いた通知・知覚の記録 — 機械的な転写）」のブロックが**もう付かない**。
- [ ] 新しい一次あらすじの被覆が**材料 1 万字級**で立っている (7 件・数千字の小粒が量産されない)。
- [ ] 移行ノイズの観察: 昔の通知行が編纂対象に戻ったため、初回の全量生成で小さなあらすじがいくつか生まれうる (一回きり、受容済み)。目に余る量なら報告してほしい。

エリスの旧あらすじ 2 件に入った付記ブロックの掃除は、まはーの手が空いたときに (簡単に編集できると言ってた件)。

## 3. 生成の段階の信号 (§2-18/19 + J)

- [ ] **通信切断からの復旧**: エリスに話しかけて、応答が流れ始める前にタブを閉じる (またはネットを切る)。開き直したときに、自動の問い合わせが走って「発言は届いています」の案内か再送導線が出る — 「履歴を確認してください」だけで放置されない。
- [ ] **再送の門番**: 既に応答が付いている発言の「再送」を (古いタブ等から) 押すと、「この発言の後に既にペルソナの発言があります。」と正直に断られる。
- [ ] **続きの生成の印**: 応答が途中で切れた発言に「続きの生成」が出て、押すと続きが生まれ、**保存された続きに対してはボタンが消える** (読み手を切断した回でも、開き直せば消えている)。
