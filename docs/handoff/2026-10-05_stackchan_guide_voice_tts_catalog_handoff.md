## 出発点

まはー:「スタックチャンアドオンなんだけど、スタックチャンにペルソナ入れて喋るまでの導入方法ガイドを saiverse.net に追加した方が良いんじゃないかな。ハードルかなり高い気がして」。

ガイドの構成を考えるために README を読み比べ、アドオンを入れる手前の段差を三つ見つけた。

1. Stack-chan から声を出すのに必須の声のアドオン (saiverse-voice-tts) が、公式カタログに載っていない。入れ方は git clone と setup.bat だけ。
2. uv を利用者が自分で入れる必要がある (SAIVerse の setup.bat は uv を入れない)。
3. 声で話しかけて返事をもらえるのは、Gemini のモデルで動くペルソナだけ (音声をそのままモデルに渡す作り)。

まはーが「Voice TTS アドオン、まだ配ってない……！！」と気づき、話は voice-tts をカタログに載せる方へ移った。**saiverse.net のガイドは、まだ一行も書いていない。** 構成案は会話の中で出しただけで、どこにも保存していない。構成案は次の 11 段だった: 用意するもの (機体 SKU 11129、Windows の PC と USB ケーブル、SAIVerse v0.3.21 以降、Gemini のモデルのペルソナ) / 声のアドオン / uv / カタログから Stack-chan Vessel / Building を作る / ファームウェアの書き込み / ペアリング / セットアップ画面 (Advanced タブを先に、次に Wi-Fi) / 身体の説明を貼る / ペルソナを移動して話しかける / うまくいかないとき。あわせて、サイトの「現実世界とのつながり」のページで Stack-chan が「開発中」となっている部分を、ガイドへの案内に差し替える予定。サイトのリポジトリは `temp/SAIVerse-docs` (origin より 10 コミット先にいて push されていない。デプロイは wrangler でまはーの手元から)。Stack-chan のセットアップ画面の写真は、まはーにしか撮れない (Stack-chan が立てる Wi-Fi スポットにつながないと開けない)。
