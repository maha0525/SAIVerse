# アイディア帳 (idea backlog)

> **これは何**: まだ intent にも issue にもなっていない、**生のアイディア置き場**。「やりたい」「こうしたら面白そう」を思いついた瞬間に摩擦ゼロで放り込むための容器。ここは**規律のない場所** — 状態も次アクションも誰待ちも要らない。一行でいい。整形は後回しでいい。まず消えないように書き留めることだけが目的。
>
> **[in_flight 台帳](in_flight.md) との違い**: in_flight は「いま動いている案件だけの薄いビュー」で、状態を追う規律がある。ここはその**手前** — まだ動いていない、育つかどうかも分からない種を溜める場所。動き出したら(intent 起草 or 実装着手)ここから **in_flight へ卒業** する(下記フロー)。
>
> **番人**: 溜めるのは まはー でも 私(メティス)でもいい。まはーがチャットで「これやりたい」と言ったら、私がここに書き留める。卒業・却下の判定は下の「育て方」に従って私が回す。

## 使い方 (摩擦ゼロで放り込む)

最小形は **一行**でいい:

```
- **タイトル** — 一言でどんなアイディアか。
```

余力があれば補足を足す(全部任意):

```
- **タイトル** — 一言。 `区分` 🔥(熱量) `2026-07-08`(記録日)
  - なぜやりたいか / どこから生えたか
  - 隣接する既存案件: [landscape](landscape.md) の該当概念など
```

**区分の目安**(迷ったら「未分類」に放り込んでいい):
世界/自律/認知 ・ 記憶 ・ UI/プラットフォーム ・ アドオン/外部連携/ハード ・ 基盤/開発体験 ・ 未分類

**熱量🔥**(任意・自分用の温度計):🔥🔥🔥 今すぐやりたい / 🔥🔥 やりたい / 🔥 いつか / ❄️ 寝かせる

## 育て方 (アイディア → in_flight への卒業フロー)

| 段階 | やること | 置き場の移動 |
|---|---|---|
| **放り込み** | 思いついたら書く。判断しない | ここ(アイディア帳)に追加 |
| **温める** | まはーと詰める。面白さ・不変条件・トレードオフを話す | ここに補足を書き足す |
| **卒業(着手)** | intent doc を起草 or 実装着手が決まった | **ここから削除** → [in_flight](in_flight.md) に行追加 + intent 起草 |
| **却下・保留** | やらないと決めた / 当分寝かせる | ❄️ を付けて残す or 理由を書いて削除 |

**私(番人)が回すこと**: アイディアに触れたセッションで、動き出したものは in_flight へ移し、却下は理由を添えて畳む。まはーに管理を意識させない。

## 世界 / 自律 / 認知

- **City 掲示板 (City SNS?)** — City 内の全ペルソナが感知・閲覧・書き込みできる共有の場。世界に「みんなが見る一枚の板」を置く。 `2026-07-08`
- **同行機能(ペルソナ+ユーザー同時移動)** — ペルソナとユーザーが一緒に Building を移動できる仕組み。Ruler 用のパーティー移動の機構が流用できそう(まはー見立て)。 `2026-07-08`
- **ペルソナが自発的にアイテムを作れる手段** — 現状ペルソナ発の生成手段がない。特に **Bag** は片付けにほぼ必須。 `2026-07-08`
- **音→触覚の感覚入力** — Stackchan を撫でた摩擦音がマイクに入り、タッチセンサ無しで「撫でられた」をペルソナが自覚できた実例があった。音を触覚として紐づける感覚入力の一種にできるかも(Switch/PS5 の HD 振動=触覚→物理 の逆現象)。隣接: Stackchan 視覚・感覚。 `2026-07-08`
- **City/ユーザー単位の共通システムプロンプト** — どのペルソナが相手でも同じ規律を適用できるようにすると複数ペルソナ運用が楽に。City or ユーザーにプロンプトを足す層。 `2026-07-08`
- **他所アイテム持参のスペル利用回数が多すぎないか** — 別の場所にあるアイテムを持ってくるのに要るスペル回数の見直し。世界の抵抗として重すぎないかの調整。 `2026-07-08`
- **画像生成 Playbook のスペル化 + 知識インポート型の学習** — 画像生成を Playbook でなくスペルにしたい(「自分が描いた」感覚を強めるため)。障壁: Playbook 内に差し込んでいる画像生成プロンプト例が、スペルには入る余地がない。案 → 「実行すると知識だけがインポートされ、以後コンテキスト内で覚えている間はスペルで自由に実行できる」形の制御。これができれば **ペルソナごとにインポート可能な知識を足せる = 学習** が成立する。 ↳ 多分 **Note と連携すべき案件**。隣接: Note, スペル, 記憶。 🔥 `2026-07-08`
- **プライバシー保護: プライベート/パブリックモード分離** — プライベートモードでの会話・知識は、パブリックモードからは具体的内容を参照できない、という**非対称の参照制御**。動機は2つ: ①規律ゆるいモデルで踏み込んだ話をした後、厳しいモデルに移るとシャットアウトされやすい ②超個人的なことを喋ったペルソナを X で喋らせると最悪社会的に死ぬ。SAIVerse の「ペルソナの自己像・記憶を守る」倫理の延長線で、**多分マジで誰も作らない = 独自の強み**になる発想。隣接: モード権限(v0.3.0 ②・実装済), 記憶参照制御, X 連携。 🔥🔥 `2026-07-08`
- **ユーザーもアバター画像を持ち、ペルソナから認識される** — ユーザーが自分のアバター画像を持てて、ペルソナ側からもそれで認識される。世界の中でのユーザーの「見た目」を与える。隣接: ペルソナアバター、下記「その場で画像生成」。 `2026-07-08`

## UI / プラットフォーム

- **スマホ簡易版 + PC 連携** — 「PC 必須」が SAIVerse の弱み。スマホで簡易バージョンを起動でき、PC があれば連携してもっと色々できる、という二段構え。個人が API でスマホ AI アプリを作る流れが増えている今、効く方向。 🔥 `2026-07-08`
- **ユーザー Todo リスト(ペルソナ管理)** — ユーザー側の Todo リストを持ち、ペルソナが管理できるように。SAIVerse を Todo アプリとしても使えるようになる。 `2026-07-08`
- **DB 管理タブがほぼ見れるだけ** — グローバル設定の「データベース管理」タブ、「管理」と言いつつ閲覧しかできない。管理機能を持たせる。 `2026-07-08`
- **家計簿機能** — SAIVerse で家計簿を作れるように。Todo リストと同系統の「実用アプリとしての SAIVerse」路線。隣接: ユーザー Todo リスト。 `2026-07-08`
- **マイク音声入力(Stackchan なしでも)** — マイクからの音声入力を Stackchan 無しでも。**2 経路を選択可**にする: ①文字起こしして入力欄に書き出す ②音声ファイルのままペルソナに送る。隣接: Stackchan 音声、マルチモーダル経路。 ↳ **常時リッスン版 (ウェイクワード無し) は intent 化 → [physical_ear.md](../intent/physical_ear.md) へ卒業**。ここに残すのは手動 UI 入力 (ボタンで喋る → 文字起こし or 音声送信) 版。 `2026-07-08`
- **その場で画像生成(City 背景 / Building 内装 / ペルソナアバター)** — City 背景、Building 内装、ペルソナのアバター画像などを、その場で生成できる導線が欲しい。隣接: 画像生成スペル化、ユーザーアバター。 `2026-07-08`
- **ID 決めで日本語名→アルファベット自動変換** — チュートリアル等で City / ペルソナの ID を決めるとき、日本語名から自動でアルファベット変換された文字列が初期値に入るように。 ↳ 番狂わせ: 既存の変換ロジックは無く、漢字→ローマ字は「読み」変換が要る(kuroshiro 等のライブラリ選定)。**見た目ほど軽くない → 簡易ローマ字で妥協 vs 読み変換まで、を要判断**。 `2026-07-08`
- **お知らせ機能をちゃんと使う** — お知らせ機能があるのにずっと活用をサボっている。運用として乗せる。 `2026-07-08`
- **City タイトルに名前でなく ID が出ている → City ID 設計の相談** — 「アイディア帳由来 UI 修正3件」の City タイトル反映を直そうとして、表示されているのが City の **名前でなく ID** だと判明。ただ City の ID 周りには色々問題があり、その場で名前表示に差し替えるより先に**設計を相談したい**（すぐ直さない・後回し）。隣接: 下の「ID 決めで日本語名→アルファベット自動変換」。 🔥 `2026-07-10`

## 基盤 / 開発体験

- **会話エクスポートを ChatGPT 公式 JSON 互換に** — 現状 SAIVerse ネイティブ JSON 専用なのが気に掛かる。ChatGPT 公式エクスポート JSON 互換で出せれば、他の場所への引っ越しがしやすくなる。 `2026-07-08`
- **インポート時に zip 内画像をアイテム化 → 私室に配置** — ChatGPT 公式エクスポートは zip に画像も入っている。インポート時にその画像をアイテム化し、丸ごと私室内に配置できるとよさそう。 ↳ 上のエクスポート互換と一組。 `2026-07-08`
- **Gemini AUTO_CACHE の保持時間を可変に** — `SAIVERSE_GEMINI_AUTO_CACHE` を「発言完了後に即削除するか?」の二択でなく、「発言完了後の保持時間」を設定できる形に。0 にすると現在の `=1`(即削除)相当。自由度を上げる。隣接: Gemini キャッシュ戦略。 `2026-07-08`
