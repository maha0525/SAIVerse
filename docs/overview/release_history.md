# リリース履歴 (Release History)

> **これは何**: 発行済みリリースの記録 (経緯・レビュー・教訓つき) と、**次のバージョンに入れる範囲の正典**。
> v0.3.0 発行後、発行記録が [`v030_release_gate.md`](v030_release_gate.md) (v0.3.0 専用の審査文書) の
> 経緯節に惰性で積まれていたのを、2026-09-05 に独立させた。
>
> **リリース判定の手順**: 「出せるか?」は必ず下の「次のバージョンの範囲」との突き合わせから始める。
> 「次に回すもの」は一括りにせず、**一件ずつ実害の有無とバージョンの約束を添えて**出す (2026-09-05 確立 —
> v0.3.8 で、前日に整理した約束 7 件のうち 1 件しか載らないまま発行した実害から)。
> **バージョンの範囲が会話で確定した瞬間に、この doc へバージョン名つきで写す。** 会話と台帳はバージョンの約束を運ばない。
>
> **大規模なバージョン**: リリース基準の篩と審査が要るバージョンは、v0.3.0 の門のように個別 doc を立てて
> ここからリンクする (2026-09-05 まはー裁定)。ホットフィックス級はこの doc の節で足りる。
>
> **発行の手続きの型**: hotfix/vX.Y.Z → PR → main (PR はまはーが内容確認してからマージ) →
> タグ vX.Y.Z (Actions が ZIP を添付、ノートは gh release edit で差し替え) → develop へ還流。
