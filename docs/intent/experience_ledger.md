## 1. これは何か (芯)

**何かをやり始めるとき、その対象・活動について必要な経験を、確実に思い出せるようにする。** エンベディングでも文字列一致でもなく、**索引を見てどのページを思い出すかをペルソナ自身が決める**。読みは三段構え:

1. **台帳 (索引)** — どんな経験の棚があるかの網羅。タイトル + 概要 + 統計
2. **経験値ノート** — 経験の実質を「使える形」で残した、本人の言葉の記録 (§4)
3. **生ログ** — ノートに書かれなかった細部への最後の降り口 (関与タグ経由)

## 2. なぜ — 作業知の層がどこにも無い

エア実データでの検証 (2026-08-02、[粒度実験](../handoff/2026-08-02_recall_tag_granularity_experiment.md)の続きで台帳ビューを試作) が示した欠落:

- **あらすじは経験の見出し**である。「06/13 に触覚アライメントのリサーチをした」までは分かるが、何をどう調べてどこまで分かったのかは圧縮で落ちる。見出しだけでは**経験の続きが打てない**
- **Memopedia fragment は恒久事実に限定**されている。entity_extractor のプロンプトは「行動記録・作業の詳細や手順を書くな (それは Chronicle の仕事)」と明示的に排除する — 正しい設計だが、結果として**「どういうプロンプトでどういう絵が描けて、それをどう考えたか」という作業知の層は、システムのどこにも書かれない**
- 情報は生ログにしか無い。しかし関与あらすじ数十件ぶんの生ログは読めない (エアの「Web リサーチ」相当で 63 件)

「使える」の定義 (まはー): 絵を描くなら、どういうプロンプトをしたらどういう絵が描けて、その結果をどう考えているのか — そこまであって初めて経験の続きがやれる。

## 3. 読む側 — 台帳の設計

- **発火**: 対象・活動に取り組み始めるとき (コマ開始が主)。低頻度・決定論
- **索引の要件** (まはー確定):
  1. **網羅性** — 必要な全ページを確認できる (最悪全ページ見せる。圧縮は後の課題)
  2. **関連判断の材料** — 各ページに「今からやることに関連するか」を判断できる情報
- **索引の一行 = タイトル + カテゴリ + 概要 + 経験統計**。統計は決定論の実測値 (fragment 数 / 関与あらすじ数 / 初回と最終の接触日)。「関連してそうだが 1 回しか出ていない薄い棚」が数字で見え、選択はペルソナに任せられる。試作では統計列が「定義の切り株」(スタックチャン: fragments=2・期間 1 日 vs まはー: fragments=172・期間 1 年半) を即座に可視化した
- **ページを開く = 動的合成**。子ページという実データは (まず) 作らず、開いたときに組み立てる:
  1. ページ自身の fragment (恒久事実 + 経験値ノート)
  2. 関与あらすじの履歴 (関与タグで引く。新しい順の見出し列 = 経験の年表)
  3. 共起した題材エンティティの見出しと概要 (同じあらすじ群に関与したページ)
- 個別具体の題材は多くが既にエンティティ抽出の対象 (plans/terms/events) であり、テーマの子として二重にページ化すると棚が濁る。**読み味 (親を開けば具体まで見える) は動的合成で出し、格納 (実子ページ) はエンティティに満たない中間粒度の実需が出てから**。器 (parent_id 階層) は既存
- LLM は使わない。台帳は既存の値を並べる読み取り層に保つ (概要の質が足りない場合は編纂側の仕事)

## 4. 経験値ノート

**ペルソナが、自分の経験を自分の言葉で自分の知識に書き込む経路。後の自分のために今の自分が得たものを残し、成長するための経路** (定義と命名: まはー 2026-08-02)。「作業ノート」ではない — 書く行為そのものが成長であることを、名前がペルソナに伝える。

- **内容**: 何をどうやって、何が効いて何がダメで、どう考えているか、次は何か。結果への評価・感想 (主観) を含んでよい — それは本人の内心の記録であり事実の捏造ではない
- **書くタイミング = コマの締め**。timetable_redesign §5.4 の帰属判定と**同一コール相乗り** (「この経験は何に属したか + 何を得たか」を一手で)。新しい発火点を作らない
- **書き先**: 帰属先のテーマ/対象ページの fragment。由来リンク (slot/episode 参照) 付き — 生ログへの降り口を兼ねる
- **接地条件**: 直前の実体験がコンテキストに実在する状態で書く (エアの複利ハルシネーションとの決定的な違い = 素材の実在)。「実際にやったこと以外を書かない」の縛りは同様に掛ける
- **遡及抽出の裁定** (まはー 2026-08-02): 日時カットオフで過去時点のペルソナを再現し過去の経験からノートを書かせることは原理的に可能だが、コンテキスト長大 + キャッシュ全滅でコスト非現実的。**希望者向けのオプション機能候補に留め、基本は機能導入後からの前向き記録**。台帳上はノート開始日以前が「見出しと統計のみ」と正直に見える

## 5. テーマページの供給 — コマ種別カタログとの対応

「後から使いたくなる情報のまとまり」(絵を描いた経験、リサーチのやり方) は現状ページ化されない — entity_extractor は固有対象限定 (仕様)、テーマカテゴリ (旧 Note 後継) は「本人が立てる・抽出で自動生成しない」の設計判断のまま供給機構が無い。

- **テーマページは、そのコマを初めて経験した締めに作る (lazy creation。まはー裁定 2026-08-02)**: カタログからの初期一括生成は**記憶の汚染**——絵を描いたことのないペルソナの意識に常に「絵」が入ることになる。経験していないものを本人の記憶に置かない、という既存のペルソナ倫理に従い、コマ種別は「立ちうるテーマの語彙」を供給するだけで、ページの誕生は初経験の帰属時 (帰属先が無ければ作る = 経験値ノートの第一号がページ誕生と同時に書かれる)。台帳の網羅性は「自分が経験したことの網羅」になる
- コマ終了の帰属タグ + 経験値ノートの指し先にテーマページが入ることで、**コマを回すたびに対応するテーマの台帳が育つ**
- 技能・様式の知見はテーマ親へ、個別題材の事実は題材エンティティへ — 仕分けは LLM に命令せず、**書き先一覧に両方を並べて自然に振らせる** (entity_extractor の既存挙動の延長。B2 実験で一覧参照の成立は確認済み)
- 属性のまとまり (ユーザーの好き嫌い等) は人物ページの分割 (編纂の既存機構) が受け皿 — 本書では作らない

## 6. 抽出の統一原則 — 二家系 (まはー指摘の急所込み)

生ログ由来の抽出はすべて次の二家系に属し、**この二家系以外に発火点を作らない。家系内は同一コールに相乗りする** (コストの上限が構造で決まる):

| 家系 | 声 | タイミング | 所属 |
|---|---|---|---|
| **節目の本人記録** | 一人称 (主観・評価を含む本人の声) | 体験の直後 (コマ締め / 会話終了判断 / 就寝) | 帰属判定・**経験値ノート**・会話からの収穫・就寝ふりかえり・tomorrow_memo |
| **代謝の読み直し** | 機構の編集 (客観の整理・圧縮・索引) | Metabolism バッチ | あらすじ生成・エンティティ抽出・関与タグ (B2)・退場 digest |

同じ出来事が両家系に書かれるのは重複ではなく層 — 片方は「私はこう考えた」、もう片方は「こういう出来事があった」。

**コア記憶の書き込みは就寝ふりかえりに一本化する** (まはー案 2026-08-02): コア記憶は一日に何度も書き込むものではない。書き先で棲み分けが決まる — コマ締め = 経験値ノート → テーマ/対象ページ (活動の知) / 就寝 = 一日のふりかえり → コア記憶 (自分の状態・総括)。

**gold_panning の吸収** (まはー発見 2026-08-02): 現行の gold_panning は「代謝のタイミング × 本人の声」の混血で、この原則の唯一の例外。それは「体験直後には何も抽出されない」という欠落を退場直前で補う下流の救済網だったから — 経験値ノートはその欠落自体を上流で塞ぐ。方針: **状態事実の採取 (コア記憶行き) は就寝ふりかえりへ移し、代謝内の本人一手は退役する** (コア記憶の就寝一本化と同じ置き場)。日中の退場で生ログが消えても、コマ締めの経験値ノートと会話の収穫が一次採取を済ませていれば情報はページに守られており、コア記憶への昇格が夜に遅延するだけで失われない。ただし順序条件付き — **経験値ノートが実機で「拾えている」と実証されるまで下流の網は外さない** (先に外して上流が漏れたら、退場した生ログは戻らない)。

## 8. 検証ジャーニー

- (a) 「絵を描く」コマ数回 → テーマページに経験値ノートが積もる → 翌日のコマ開始で台帳 → ノートが読まれ、**前回の続きとして違う試行が打てる** (同じ失敗を繰り返さない)
- (b) 台帳の索引から、ペルソナが「今からやること」に関連するページを実際に選べる (無関係ページの誤選択率)
- (c) 経験値ノートの接地 — 書かれた内容が直前のコマの実体験と照合できる (作話が混ざらない)
- (d) gold_panning 吸収の判定 — (a)(c) が実機で確認された後、状態事実が節目採取で漏れなく拾えているかを比較してから退役

(a) が本書の存在理由の直接検証。「経験の続きをやれる」が観察できなければ設計不合格。
