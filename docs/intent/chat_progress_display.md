# 返事を待つ間の表示 (送信から返事まで)

**ステータス**: 検証待ち (実装はブランチ feature/chat-progress-display の PR。チャットの実機の画面ではまだ見ていない)

## 芯

チャットで送ってから返事が出るまで、画面は「いま何をしているか」を誰にでも分かる言葉で出す。
自分の吹き出しは送った瞬間から自分の名前と添付画像で出す。開発用の名前 (Playbook・ノード・
"Processing..." など) は画面に出さない。

## 困っていたこと (2026-10-22 まはー報告)

1. 送った直後の自分の吹き出しが「You」になる。起動時の `/api/user/status` 一回だけで名前を
   覚えていたので、起動時に繋がらなかった回やプロフィールを変えた後に名前が空のまま残った。
2. スピナーの横に `Processing...` や `track_user_conversation / main_line_response` が出る。
   各ノードが出す status イベント (`"<playbook> / <node>"`) をそのまま表示していた。
3. 画像を添付して送ると、吹き出しに画像が出ず `Attachment 1` (壊れた画像の代わりの文字) が出る。
   添付は `FileReader.readAsDataURL` の結果 (既に `data:<mime>;base64,` 付き) を持っているのに、
   送信直後の吹き出しはそこへもう一度前置きを付けて壊していた。サーバーの行が届くと直るので
   気付きにくかった。

## 決まったこと

- **段階と文言の持ち主を分ける。** バックエンドは段階の名前 (`phase`) と差し込む固有名だけを
  status イベントで送る (`sea/progress_events.py`)。文言はフロント (`frontend/src/lib/chatProgress.ts`)
  だけが持ち、日本語・英語の表 (`messages.json` の `chatProgress.*`) から引く。
- **段階** (画面の文言はまはーの例に合わせた):

  | 段階 | 誰が決めるか | 表示 |
  |---|---|---|
  | recording / uploading | 画面 (送信した瞬間。添付があれば uploading) | あなたの発言をデータベースに記録しています / 添付ファイルをアップロードしています |
  | preparing | 画面 (発言の保存が済んだ合図 `user_message_id`、続き・やり直しの開始) | 返事の準備をしています |
  | building_request | バックエンド (文脈の組み立ての直前) | OpenAIサーバーへの送信データを構築しています |
  | awaiting_response | バックエンド (LLM へ送る直前。全経路) | OpenAIサーバーからの応答を待っています |
  | thinking | 画面 (思考の流し込み) | エリスが考えています |
  | replying | 画面 (本文の流し込み) | エリスが返事をしています |
  | running_tool | バックエンド (スペルを実行する直前) | 「記憶のページを読む」を実行しています |
  | finishing | 画面 (返事の確定の後。次の段階が来れば上書き) | 仕上げの処理をしています |

- 接続先の名前は、実際に送る model の接続先の表示名 (`builtin_data/providers/*.json` の
  `display_name`) から括弧の補足と末尾の "Server" を落としたもの。分からなければ「AIサーバー」。
- `phase` の無い status は二種類だけ: Playbook / ノード名の足跡 (`playbook` / `node` /
  `playbook_chain` を持つ — 表示を変えない) と、サーバーが利用者向けに書いた文 (記憶の非常整理の
  通知など — そのまま出す)。足跡は調査用に送り続ける。
- Playbook の実行の包み (`sea/runtime_runner.py` の `wrapped_event_callback`) が本文を連鎖の名前で
  書き換えるのは足跡 (`node` を持つ status) だけ。以前は利用者向けの文まで連鎖の名前で潰していた。
- 進み具合を送れなくても返事は止めない (送り手が例外を記録して飲む)。
- 自分の名前とアバターは `/api/user/status` を読むたび (5 秒おきの状態の追従を含む) に覚え直す。
  名乗りの無いユーザーの行は、覚えている名前で描き、それも無いときだけ「あなた」と出す。

## 範囲の外

- 応答の吹き出しの「思考の折りたたみ」の見出し ("Thinking..." / "Thought process") は別の表示で、
  今回は触っていない。
- 記憶の整理 (metabolism) の文言はサーバーが書いた日本語のまま (英語表示でも日本語)。
