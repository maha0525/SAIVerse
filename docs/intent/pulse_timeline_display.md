# Intent: Pulse タイムラインの表示

**ステータス**: 検証待ち。テーマ追従の修正は develop に取り込み済み。実機での見え方の確認は未完了。
**関連**: [ライトモードの issue](../issues/pulse_timeline_light_mode_broken.md)、[既存の表示・編集機能の記録](persona_cognition/handoff_2026-05-26.md)

## 全体と責任

ユーザーが SAIMemory の Pulse 一覧を開き、展開したメッセージ・入力プロンプト・Pulse 間の入力を読み、必要なら既存の line_role / scope 編集を行う画面。表示の色は選択中の UI テーマに従う。取得した本文・タグ・並び順と保存 API の契約は変えない。

API が返す記録から、一覧、展開、select、未保存の印、保存操作までの表示は `PulseTimelineViewer` が所有する。背景・本文・補助文字・境界線は `globals.css` の既存テーマ変数を使い、役割・Spell・注意の色はメモリー画面の既存パレットを明暗で使い分ける。データ取得側や認知側にテーマの責務を持たせない。

## 不変条件

- 白いモーダルの中にダーク固定のヘッダー・入力欄を残さない。select の候補も選択中のテーマで読める。
- 長い本文とプロンプトは改行を保ったまま折り返す。狭い幅では操作列を折り返し、縦スクロールを Viewer が担う。
- 表示を直すためにメッセージの意味・scope による既存の薄表示・編集の保存内容・Pulse 起動の挙動を変更しない。

## 検証の旅と残る境界

合成レスポンスによる一覧→展開→select 編集→折りたたみ→再展開を、実コンポーネントのイベントハンドラーに対して隔離テストする。これはブラウザーのレイアウト検証ではない。

ライト/ダーク、360/960/1600 CSS px、長い日英混在本文・入力プロンプト・編集途中・更新/閉じる/再表示をブラウザーで実視認する。今回の dot クラウドブラウザーは隔離 localhost を `net::ERR_BLOCKED_BY_CLIENT` で拒否したため、この確認は未完了。本番のペルソナ、LLM、記憶の書き換えによる代替検証は行わない。
