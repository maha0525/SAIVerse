# Grok (xAI) APIキーの取得方法

Grok の API は xAI が提供しています（公式ドキュメントでは、運営元が「SpaceXAI」と表記されています）。

## 1. xAIアカウントの作成

1. [xAI Console](https://console.x.ai/) にアクセスします。
2. アカウントを作成し、利用規約に同意します。
3. API を使うには、先にクレジットを購入してアカウントに入れておく必要があります（公式のクイックスタートの手順です）。

## 2. APIキーの生成

1. ログイン後、Console の [API Keys のページ](https://console.x.ai/team/default/api-keys) に移動します。
2. 新しいキーの作成ボタンを押します。
3. キーに名前を付けて作成します。
4. 表示されたAPIキーをコピーします。

> **重要**: API キーはパスワードと同じように扱ってください。他人に見せたり、公開の場所に貼ったりしないでください。

## 3. 料金について

### 文章を扱うモデルの料金（2026年10月時点、[公式の料金ページ](https://docs.x.ai/developers/pricing)で確認）

どれも 100 万トークンあたりの米ドルです。

| モデル | 入力 | キャッシュ入力 | 出力 | 扱える長さ |
|--------|------|---------------|------|-----------|
| Grok 4.3 | $1.25 | $0.20 | $2.50 | 100万トークン |
| Grok 4.20（推論あり / 推論なし） | $1.25 | $0.20 | $2.50 | 100万トークン |
| Grok 4.5 | $2.00 | $0.30 | $6.00 | 50万トークン |
| Grok 4.6 | $2.00 | $0.50 | $6.00 | 50万トークン |
| Grok 4.7 | $2.00 | $0.50 | $6.00 | 50万トークン |

どのモデルも、1回の入力が 20 万トークン以上になると、そのリクエストのトークンすべてが2倍の単価で計算されます。

### 画像生成の料金（Grok Imagine Image 2.0）

2026年10月時点、[公式の料金ページ](https://docs.x.ai/developers/pricing)で確認した値です。

| 品質 | 解像度 1k | 解像度 2k |
|------|-----------|-----------|
| low | $0.04 / 枚 | $0.06 / 枚 |
| medium | $0.06 / 枚 | $0.08 / 枚 |

参照画像を渡して編集する場合は、入力する画像1枚につき $0.01 が加わります。

`generate_image` ツールの `grok_imagine` がこのモデルを使います。ツール側の品質が `low` なら low・1k、`medium` なら medium・1k、`high` 以上なら medium・2k で生成します。

## 4. SAIVerse で使えるモデル

- **Grok 4.7**: xAI がいま「最新の主力モデル」と位置づけているモデルです。迷ったらこれを選んでください。
- **Grok 4.5 / Grok 4.6**: Grok 4.7 と同じ値段帯のモデルです。
- **Grok 4.3**: 上の表でいちばん安く、扱える長さもいちばん長いモデルです。チュートリアルの既定もこのモデルです。
- **Grok 4.20 Beta (Reasoning) / Grok 4.20 Beta (Non-Reasoning)**: 推論あり / 推論なしの2種類です。xAI 側ではすでに正式版の「Grok 4.20」になっていて、SAIVerse が使っているベータ版の名前は正式版の別名として同じモデルにつながります。値段は Grok 4.3 と同じです。
- **Grok Imagine Image 2.0**: 画像生成モデルです（文章からの生成と、参照画像つきの編集に対応）。

文章を扱うモデルは、どれも画像を読み取れます。

以前同梱していた Grok 4 (0709) と Grok 4.1 Fast Reasoning は、2026年5月15日に xAI 側で提供が終わり、呼ぶと Grok 4.3 が答えるようになりました。呼んだ名前と実際に答えるモデルが一致しないため、2026年9月に同梱モデルから外しました。

## 5. 特徴

- **最新情報について**: Grok は、検索ツール（Web Search / X Search）を有効にしたときだけ最新の情報を取りにいけます。SAIVerse の Grok の接続では検索ツールを使っていないので、学習した時点までの知識で答えます。
- **データの扱い**: xAI は、API で送った内容と返ってきた内容を、本人の明示的な許可なしに学習には使わないと公表しています。不正利用の調査のため、既定では 30 日間保存されたあと自動で削除されます。

## 環境変数

SAIVerseでは以下の環境変数名を使用します：
```
XAI_API_KEY=ここに取得したキーを貼り付け
```
