## まはーとの議論が要る未合意事項 (5 件)

1. **あらすじは何本あれば健康か。** 事故 1 の根本。字数の約束はあるが本数の約束が無く、
   実行前の見積もりが唯一の権威になっている。決まらないと、旅を自動化しても各駅で測る値が無い。
2. **確認を出せないときの既定はどちらを向くべきか。** 現状は三方向に割れている — Playbook 権限は拒否、
   あらすじ生成は無確認でスキップ、**副作用のあるスペルは自動承認**。三つとも同じ動機を
   コード内の説明文に書いているのに結論が違う。まはーの「止めるのではなく記録し、明示し、選択してもらう」
   をどう適用するかは、この三方向のどれとも一致しない。
3. **安全弁 3 つの閾値を誰のために何を守る数字として決め直すか。** 10 万字 / 8 秒 / 10 件。
   現状の値が正しいかを判断する材料が実装以外に無い。
4. **v0.3 の出荷状態をテストで見るか。** `tests/conftest.py` の自動適用の仕掛けが全テストで
   自律の止め具を外すため、スイートは一貫して v0.4 の世界を検証している。出荷状態を見るのは 1 ファイルだけで、
   「画面から作ったアラームは止め具を通らない」という非対称はどのテストも触れていない。
5. **隔離環境で確認できないものをどう減らすか。** まはーの方針 (「確実に最初に隔離環境で検証を通しておいて、
   どうしても本番でしか見れないものの数を減らす」) を台帳に落とすには、各項目に
   「隔離できるか / できないなら何が妨げているか」の列が要る。今回の 215 項目にはまだ無い。
