**アドオンの件から、削除の族全体に効く規範が出た (まはー原文)。**

> ユーザー操作の結果はその影響範囲をユーザーの期待と合わせる。
> 不可逆な操作であるほどこの規範は厳しく守られるべきで、削除はその筆頭。

期待がはっきりしない不可逆な操作は、どちらかへ倒さずに訊く。
ただし**訊いてよいのは、利用者が消すかどうかを決めてよいものだけ** — 他人の記憶に関わるものは訊く対象に出さない
(訊いて「はい」と言われたら記憶の改竄になる)。部屋で交わされた会話は残ることを伝えるだけ、
ペルソナ本人の記憶の中身はそもそも巻き込まない。
[normal_behavior.md](normal_behavior.md) の冒頭に独立した節として置き、
記憶・部屋・物・ペルソナ・アドオン・世界のデータベースの 7 つの流れへ当てた。
**この規範と、エラー時の規範 (「止めるのではなく、記録し、明示し、選択してもらう」) は別物。**
統合担当は一度これを混ぜて `FLOW-29` の問いを誤った形で立て、指摘を受けて問いごと取り下げ、まはーに戻された。
