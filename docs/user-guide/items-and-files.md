# アイテムとファイル

SAIVerse のアイテム（建物に置かれた物・ペルソナの持ち物）と、チャットへのファイル添付の扱い。

## 建物のアイテム（右サイドバー）

チャット領域ヘッダの **Info** ボタンで右サイドバー（`RightSidebar.tsx`）を開くと、現在いる建物の情報が表示される:

- **現在地** — 建物名と Building 設定へのボタン
- **在室者** — その建物にいるペルソナ一覧（クリックでライフビュー等のペルソナメニュー）
- **アイテム** — その建物に置かれているアイテム一覧
- **観測値** — Observer 系 Fixture がある場合、その観測データ（名前 / 値 / 記録時刻）

### AI コンテキストへの出し入れ

建物アイテムはそれぞれ「**AI コンテキストに含める / 除外**」をトグルできる（`is_open`）。含めると、その建物にいるペルソナのコンテキストにアイテム内容が載る（＝ペルソナがそれを認識する）。除外すると載らない。

## ペルソナの持ち物（インベントリ）

ペルソナメニュー →「**持ち物**」でインベントリ（`InventoryModal.tsx`）を開くと、そのペルソナが手に持っているアイテムを確認できる。ペルソナは `pickup` / `place` 相当の操作でアイテムを拾ったり置いたりする（→ [concepts/item.md](../concepts/item.md)）。

## アイテムの閲覧・編集

アイテムをクリックすると詳細（`ItemModal.tsx`）が開く:

- **名前 / 説明** の編集（メタ情報）
- **本文**の表示（Markdown / プレーンテキストの切替）と編集・保存
- ドキュメント・画像などタイプに応じた表示

## チャットへのファイル添付

メッセージ入力欄では、テキストと一緒にファイルを添付できる:

- 画像・音声・動画などを添付（複数可）
- ドラッグ&ドロップ、貼り付け、または添付ボタンから
- アップロード中・エラー時は送信がブロックされる（アップロード完了まで待機）

添付は `saiverse://` URI 経由でペルソナから参照される（→ [reference/saiverse-uri.md](../reference/saiverse-uri.md)）。
