# ワールドビュー

SAIVerse のメイン画面「ワールドビュー」の使い方。左サイドバー・チャット領域・右サイドバーの3つで構成される。

> この文書は実 UI（`frontend/src/app/page.tsx` / `components/Sidebar.tsx` / `RightSidebar.tsx` / `PersonaMenu.tsx` 等）に基づく。

## 左サイドバー

ハンバーガーメニュー（またはスワイプ）で開閉する。内容:

- **ペルソナ作成** — ペルソナ作成ウィザードを開く
- **場所** — 現在の City の Building 一覧。Region があれば折り畳み表示。＋で Building を新規作成
- **システム** — お知らせ / API 使用状況 / チュートリアル / アドオン（開発者モード時はフェノメノンも）
- **フッター** — 設定（グローバル設定）/ ユーザープロフィール

### Building の選択は「閲覧」（移動ではない）

Building をクリックすると、その Building の履歴・在室者・チャットを**閲覧**する状態に切り替わる。**この時点では移動しない**（サーバ上の現在地は変わらない）。実際の入室は、その Building で**発言した時**に起きる（`/chat/utter` が発言と同時に入室を行う）。

- ハイライトは「いま閲覧している Building」
- 自分が実際に居る Building には、別途ユーザーアイコンのマーカーが付く（閲覧中の場所と現在地が違うと一目で分かる）

## チャット領域

### ヘッダ（右側のボタン）

| ボタン | 機能 |
|---|---|
| 街マップ | City の空間マップ（[街マップ](city-map.md)）を開閉 |
| People 管理 | 在室ペルソナの召喚・解散を行うモーダル |
| Info | 右サイドバー（在室者・情報）の表示切替 |

### メッセージ入力

- テキストを入力してペルソナに話しかける
- **`Ctrl+Enter`（Mac は `Cmd+Enter`）で送信**。`Enter` 単体は改行
- 画像・音声・動画などのファイルを添付できる（複数可。アップロード中は送信を待機）
- コンテキストプレビューで「ペルソナに実際に何が見えているか」を送信前に確認できる

## 右サイドバー（Info）

ヘッダの Info ボタンで開く情報パネル。現在いる建物について表示する（→ [アイテムとファイル](items-and-files.md)）:

- **現在地** — 建物名 + Building 設定
- **在室者** — その建物のペルソナ一覧。クリックで**ペルソナメニュー**が開く
- **アイテム** — 建物内のアイテム（AI コンテキストへの出し入れトグル付き）
- **観測値** — Observer 系 Fixture の観測データ（あれば）

### ペルソナメニュー

各ペルソナに対して以下を操作できる:

- **ライフビュー** — 自律行動の観察・制御（後述 / [自律行動モード](../features/autonomous-mode.md)）
- **記憶** — [メモリービュー](memory-view.md)（チャットログ / Chronicle / Memopedia / インポート 等）
- **スケジュール** — 定時実行の管理
- **タスク** — タスク管理
- **設定** — [ペルソナ設定](persona-settings.md)
- **持ち物** — [インベントリ（所持アイテム）](items-and-files.md)

## 自律行動

ペルソナの自律行動は、**ペルソナメニュー → ライフビュー**から制御する（サイドバーに全体スイッチはない）。ライフビューには per-persona の再生 / 停止トグルと間隔設定がある。

> ⚠️ **ペルソナ同士の自動会話は未実装**（交流 Track が未成立）。複数ペルソナが在室していても、彼らが自発的に会話し合うことはない。複数在室の状態でユーザーが発言した場合は、その場のペルソナと会話できる。
