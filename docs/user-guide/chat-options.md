# チャットオプション

メッセージごと・ペルソナごとに、使うモデルや送信量などを調整する設定。チャット入力欄付近のオプションボタンから開く（`ChatOptions.tsx`）。

## 設定項目

### モデル

- 送信のたびに使用モデルを選べる
- **★ お気に入り**に登録したモデルは先頭にまとまって表示される

### キャッシュ（このペルソナ）

- プロンプトキャッシュの設定。キャッシュ TTL の上書きなど

### データ送信量の管理

- **メッセージ数上限** — LLM に送る会話履歴の上限。コンテキスト超過エラーが出るときは下げる
- **履歴の新陳代謝** — ON にすると履歴ウィンドウの始点を固定してキャッシュヒット率を上げ、上限到達時にまとめて整理（バルクトリミング + Chronicle 生成）。OFF は従来のスライディングウィンドウ
- **代謝後の保持件数** — 上限到達時にここまで古い履歴を整理する
- **画像埋め込み上限** — 送信する画像の上限

### モデル設定の保存

現在の設定を:

- **詳細編集**（モデル JSON 全体を編集）
- **別名で保存**（新しいモデルとして）
- **上書き保存**（現在のモデルに）※ビルトインの場合は user_data に上書き用ファイルが作られる

## ツールの使い方の指定

「ツールを使わず話す」「使うツールを指定する」「ペルソナに委ねる」といったツールの使い方は、別途ツールモード選択（`ToolModeSelector`）で切り替える。
