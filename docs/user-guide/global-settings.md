# グローバル設定

SAIVerse 全体の設定。左サイドバー フッターの歯車アイコン（設定）から開く（`GlobalSettingsModal.tsx`）。左のタブで切り替える。

## タブ

| タブ | 内容 |
|---|---|
| **環境** | API キー・環境変数の設定（→ [reference/environment-vars.md](../reference/environment-vars.md)） |
| **ワールドエディタ** | City / Building / ペルソナ / アイテムの編集（→ [ワールドエディタ](world-editor.md)） |
| **データベース管理** | データベースのバックアップ・管理 |
| **モデルロール** | 役割ごとに使うモデルの割り当て（モデルロール設定） |
| **モデル管理** | プロバイダとモデルの追加・編集・接続テスト（→ [reference/providers.md](../reference/providers.md)） |
| **Playbook権限** | Playbook の実行権限設定 |
| **情報** | SAIVerse について（バージョン等） |
| **便利機能** | アイテム概要の一括生成など |

## 入退室ログの表示

「環境」タブの「入退室ログ」で「表示」「非表示」を選ぶと、チャット上のユーザー・ペルソナの入室・退室通知を切り替えられます。既定は「表示」で、選択は自動保存され、再起動後も残ります。

Building 設定で「グローバル設定に合わせる」を選んだ部屋に適用されます。「表示」「非表示」を明示した部屋は、その部屋の選択が優先されます。非表示にしても記録は消えず、ペルソナが受け取る移動情報や会話の文脈も変わりません。アイテム取得や警告など、ほかの通知は表示されます。

入退室通知だけのページになったときは、チャット上部の「以前のメッセージを読み込む」から前の会話へ進めます。古い記録のうち、通知の種類が記録されていないものは表示を保ちます。

## モデル管理タブ

- **プロバイダ**: 新規追加 → プロトコル選択（`openai_compat` / `ollama_compat`）→ base_url / api_key_env 入力 → 接続テスト
  - キーが要るプロバイダの行には **「キー設定」** ボタンがあり、API キーの値をその場で入力できる（`.env` に保存され、再起動なしで次の返答から効く。取得方法ガイドがあるプロバイダはリンクも出る）
- **モデル**: 新規追加 → 基本項目・水位の専用欄と追加設定 JSON を編集 → 保存。JSON に水位 (`metabolism_high_chars` / `metabolism_target_chars`) を書いた場合は、保存時に空の専用欄へ移ります (`null` は `none`)。専用欄に既に値があればその値が優先されます。既存モデルを編集・複製するとき、数値や `null` 以外の水位は JSON に残り、保存時にエラーを表示します。たとえば `"150000"` は文字列なので、JSON の値を数値の `150000` に直すか、専用欄へ数値を入力してください。

ビルトインのモデル/プロバイダを編集して保存すると、`~/.saiverse/user_data/` に上書き用のファイルが作られる（ビルトイン本体は変更されない）。
