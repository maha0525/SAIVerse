# ペルソナ設定

ペルソナ 1 体ごとの設定画面（`SettingsModal.tsx`）。右サイドバーの滞在ペルソナをクリックして開くペルソナメニューで、「Settings（AI設定）」を押すと開く（→ [ワールドビュー](world-view.md)）。

この文書では、画面に並んでいる順に各項目を説明する。

## 保存と反映

- ほとんどの項目は、画面下の「保存」を押したときに記録される。例外は「事前実行スペル」の「追加」「削除」と、デバッグコントローラーのボタンで、どちらも押した時点で実行される。
- ペルソナには、応答のたびに head（プロンプトの先頭部分。この画面の説明文では「前置き」と書かれている）が送られる。システムプロンプト・リンクユーザー・Memory Weave コンテキスト・Chronicle（あらすじ）の読み込み文字数・Memopedia索引の常時表示・スペルの一覧は head に入るので、保存しても、head が組み直されるまではペルソナに届かない。
- head は Metabolism のたびに組み直される。Metabolism とは、ペルソナに送る会話が「整理をはじめる量」（グローバル設定やモデル定義で決める値）を超えたときに、古い部分をあらすじにして、送る範囲から外す処理のこと（この画面の説明文では「記憶の整理」と書かれている。→ [Metabolism](../concepts/metabolism.md)）。すぐに反映したいときは、ペルソナメニューの「溜まった会話をあらすじにまとめる」を押す。あらすじにする会話が無くても、押せば head は組み直される。

## 名前

名前はこの画面では変えられない。ワールドエディタのペルソナの欄で変える（→ [ワールドエディタ](world-editor.md)）。

## モデル

| 画面の項目 | 使われる場面 | 空欄のとき |
|---|---|---|
| **デフォルトモデル** | 会話の応答。アラームや外部からのイベントに応えるときもこのモデルを使う | グローバル設定の「モデルロール」タブの「標準モデル」を使う |
| **軽量モデル（任意）** | ペルソナが `run_playbook` スペルで Playbook を動かしたときの、その Playbook の中の処理 | 「モデルロール」タブの「軽量モデル」を使う。それも未設定なら組み込みの既定モデル |
| **Memory Weaveモデル（任意）** | Metabolism の中で行う、あらすじ（[Chronicle](../concepts/chronicle.md)）の作成などの処理 | 「モデルロール」タブの「Memory Weaveモデル」を使う。それも未設定なら組み込みの既定モデル |

添付した画像・音声・動画の要約に使うモデルは、ペルソナごとには選べない。グローバル設定の「モデルロール」タブで、全ペルソナ共通の値を選ぶ。

- Memory Weave は、あらすじ（Chronicle）や [Memopedia](../concepts/memopedia.md) といった長期記憶を作る処理と、それをペルソナに送る内容へ入れる処理をまとめた呼び名。
- 軽量モデルの選択肢「なし（デフォルトを使用）」は、このペルソナのデフォルトモデルではなく、「モデルロール」タブの軽量モデルを使うという意味。
- チャットオプションの「モデル」でモデルを選んでいる間は、全ペルソナがそのモデルを使い、ここで選んだデフォルトモデルより優先される。
- デフォルトモデルを別のモデルに変えた場合は、保存した時点から使われる。空欄に戻した場合は、SAIVerse を再起動するまで前のモデルのまま動く。

## デバッグコントローラー

「Embedding 一括生成」ボタンを押すと、あらすじ（Chronicle）・Memopedia のページ・Fragment（Memopedia に書かれた知識の最小単位）のうち、検索用の埋め込み（Embedding）がまだ作られていないものをまとめて作る。下の「自動想起」で記憶を探すときは、この埋め込みを使う。Metabolism のたびに同じ処理が自動で走るので、普段は押さなくてよい。

## キャッシュ維持の設定

モデル側のキャッシュ（毎回送る head を、読み込み済みのまま一定時間残しておく仕組み）を、会話が途切れている間も切らさないための設定。明示的キャッシュ（送る内容のどこまでをキャッシュするかを、呼び出す側が指定する方式）を使うモデルでだけ働く。Anthropic のモデルは、モデル定義で別の指定が無ければ明示的キャッシュを使う。

- **キャッシュ維持** — 「既定 (ON)」「ON (TTL 接近で前倒し)」「OFF (TTL 無視 / 低頻度向け)」から選ぶ（TTL はキャッシュの有効時間のこと）。ON のときは、キャッシュの残り時間が少なくなると、同じ head でモデルを 1 回だけ呼んで、キャッシュの有効時間を延ばす。この呼び出しの応答は捨てられ、会話にも記憶にも残らないが、呼ぶたびに API 料金（head をキャッシュから読む分）がかかる。OFF にすると延ばさない。
- **キャッシュ閾値 (0.0–1.0)** — キャッシュの有効時間のうち、残りがこの割合になった時点で延ばす。空欄なら 0.3。0 より大きく 1 より小さい値でないときも 0.3 として扱う。キャッシュ維持が OFF のときは入力できない。
- ワールドエディタのペルソナの欄で「自律行動」を無効にしているペルソナでは、キャッシュ維持が ON でも、延ばすための呼び出しは行わない。

## 応答待ち Track 自動 pause 閾値

画面の項目名は古い仕組みのもの。いまこの欄で指定するのは、最後のやりとりから何分話しかけが無ければ、その会話を終わったものとして扱うか、という時間。既定は 30 分で、0 か空欄にすると既定に戻る。

v0.3 では、この区切りを使って動く自律行動がまだ動かないので、値を変えても、話しかけたときの応答やペルソナの記憶は変わらない。会話を終わったものとして扱っても、そのことはどこにも記録されない。

## Chronicle 自動生成

有効（既定）のとき、Metabolism で送る範囲から外す古い会話を、あらすじ（Chronicle）にまとめる。あらすじは Memory Weaveモデルで作るので、作るたびに API 料金がかかる。確認が出るかどうかは、Metabolism が起きた場面で決まる。

| Metabolism が起きた場面 | あらすじを作るか |
|---|---|
| ユーザーへの応答のあと | チャット画面に確認を出し、許可されたときだけ作る |
| 応答を作る前に、送る量がすでに「整理をはじめる量」を超えていたとき | 確認なしで作る |
| アラームや外部からのイベントに応えたあと | 下の「自律行動中も記憶整理（Chronicle生成）を行う」が有効なら、確認なしで作る。無効なら作らない |
| しばらく会話が無くキャッシュが切れている間に、SAIVerse が前もって行う Metabolism | 「自律行動中も記憶整理（Chronicle生成）を行う」が有効なら作る。無効ならこの Metabolism そのものを行わない |
| ペルソナメニューの「溜まった会話をあらすじにまとめる」を押したとき | 確認なしで作る |

ユーザーへの応答のあとの確認で許可しなかった（拒否した、または 60 秒以内に答えなかった）ときは、今回はあらすじを作らず、古い会話も送る範囲に残す。送る量が「整理をはじめる量」を超えたままなら、次に話しかけたとき、応答を作る前に確認なしで作られる。

無効にすると、どの場面でもあらすじを作らない。自動の Metabolism では、古い会話があらすじにならないまま送る範囲から外れる（会話の記録そのものは消えない）。「溜まった会話をあらすじにまとめる」と、メモリービューの「Chronicle」タブからのあらすじ作りもできなくなる。

あらすじになっていない過去のメッセージがあるときは、この項目の下に、その件数と、まとめてあらすじにした場合の推定コストと LLM 呼び出し回数が表示される。

## Chronicle（あらすじ）の読み込み文字数

head に入れるあらすじの、合計文字数の目安。既定は 20000 字で、空欄にすると既定に戻る（環境変数 `SAIVERSE_CHRONICLE_CHAR_BUDGET` を設定している場合は、既定の代わりにその値）。増やすとペルソナは過去の出来事を詳しく知っていられるが、送る量が増える。「Memory Weave コンテキスト」が無効のときは使われない。

## 自律行動中も記憶整理（Chronicle生成）を行う

項目名には「自律行動」とあるが、v0.3 でこの項目を切り替えて変わるのは、ユーザーが確認に答えられない場面であらすじを作るかどうか。場面は、上の「Chronicle 自動生成」の表にある次の二つ。

- アラームや外部からのイベントに応えたあとの Metabolism。有効（既定）なら確認なしで作る。無効なら作らず、古い会話はあらすじにならないまま送る範囲から外れる。
- しばらく会話が無くキャッシュが切れている間に、SAIVerse が前もって行う Metabolism。有効なら行い、無効なら行わない。

「Chronicle 自動生成」が無効のときは、この項目に関わらずあらすじを作らない。

## 自動想起（ふと浮かんだ記憶）

有効（既定）のとき、応答を作る前に、いまの会話に関係しそうな過去の記憶を探して、最新の発言の直前に添える。チャット画面にも「ふと浮かんだ記憶」として折りたたんで表示される。無効にすると添えない。無効でも、ペルソナがスペルで自分から記憶を探すことはできる。

## Memory Weave コンテキスト

有効（既定）のとき、head にあらすじ（Chronicle）を入れる。ペルソナはこれで、送る範囲から外れた過去の出来事を知っていられる。無効にすると入れないので、送る量は減るが、送る範囲から外れた出来事を head から知ることはできなくなる。Memopedia を head に入れるかどうかは、この項目ではなく「Memopedia索引の常時表示」で決まる。

## Memopedia索引の常時表示

有効（既定）のとき、Memopedia のページの目次（各ページの概要付き）を head に入れる。ペルソナが自分の知識の全体を見渡しやすくなるが、送る量が増える。

## コア記憶の文字数目安

ペルソナが自分で書き込むコア記憶（いつも head に入る記憶）の、合計文字数の目安。既定は 2000 字で、空欄にすると既定に戻る。ペルソナがスペルでコア記憶を書いたとき、合計がこの文字数を超えていると、スペルの結果に「目安を超えています。整理を検討してください。」と添えられる。超えても内容が切り詰められることはない。

## スペル

有効（既定）のとき、ペルソナは発言の中に `/spell` で始まる行を書いて、スペル（記憶の検索や書き込み、手帳など、ペルソナが使える道具）を唱え、その結果を見て発言を続けられる。head には、使えるスペルの一覧と使い方が入る（→ [スペル](../concepts/spell.md)）。

無効にすると、発言の中に書かれたスペルは実行されず、下の「事前実行スペル」も動かない。head には「スペルは現在使用できません」という案内が入る。

## リアルタイム情報

有効（既定）のとき、応答のたびに、送る内容の末尾近くへ次の情報を添える。

- 現在時刻
- そのペルソナが前回発言した時刻
- Unity 連携が動いているときは、プレイヤーとの距離と、プレイヤーが見えているかどうか

無効にすると、これらを送らない。ただし「事前実行スペル」の結果は、この項目が無効でも送られる（「スペル」が有効で、事前実行スペルが登録されている場合）。

## 事前実行スペル

応答のたびに自動で唱えるスペルを登録する。結果は「リアルタイム情報」と同じ場所に添えて送られ、画像を返すスペルなら画像も添えられる。結果はペルソナの記憶には残らない。

- 「スペルを選択...」でスペルを選び、必要なら引数と「ラベル (表示名)」を入れて「追加」を押す。「追加」と「削除」は押した時点で記録される（「保存」は要らない）。
- ラベルは、送る結果の頭に付く名前になる。空欄ならスペル名が付く。
- ペルソナがいる建物の設定で登録した事前実行スペルも、一緒に唱えられる。
- 「スペル」が無効のときは唱えられない。

## リンクユーザー

このペルソナと結び付けるユーザーを選ぶ。選んだユーザーの名前は、head の冒頭にある SAIVerse 共通の文章のうち、ペルソナが誰と暮らしているかを書いた部分に入る。「なし（「ユーザー」と表示）」を選ぶと、そこには英語で "the user" と入る。

## アバター

画面に表示するペルソナのアイコン画像。ペルソナに送る内容には使われない。

## 外見画像（ビジュアルコンテキスト）

ペルソナの姿を描いた画像で、アバターとは別に持つ。同じ建物にいる他のペルソナに送られる「部屋の様子」に、このペルソナの姿として添えられる。

## 説明

このペルソナについての短い説明文。ワールドエディタのペルソナの欄の「説明」と同じ値で、ペルソナに送る内容には使われない。

## システムプロンプト

ペルソナの性格・背景・話し方などを定める、いちばん基本の指示。head の「## あなたについて」という見出しの下に入る。

## この画面に無い設定

自律行動（ペルソナが自分から考えて動くこと）の設定は、v0.3 ではこの画面に無い。v0.3 では自律行動そのものが動かない。
