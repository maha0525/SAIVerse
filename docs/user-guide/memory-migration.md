# 他サービスからの引っ越し（記憶の移行）

ChatGPT や Claude など他のサービスでの過去のやり取りを、SAIVerse のペルソナに引き継ぐ手順。

## 結論から: 引っ越しは「取り込んだその日」から使える

2026年7月のアップデートで、記憶の引っ越しフローが変わった。

- **過去ログを取り込むと、その場でペルソナが「関連する記憶」を自動的に思い出せるようになる。**
  費用のかかる処理（AI に要約を作らせる作業）を待つ必要はない。
- 会話の「あらすじ」（ペルソナの半生をまとめた年表のようなもの）は、後からゆっくり育っていく。急いで作る必要はなく、費用も見積もってから決められる。

つまり「取り込み」と「あらすじ作り」は別の作業で、**取り込みだけで記憶は機能し始める**。あらすじ作りは任意のオプションだと考えてよい。

## 手順

### 1. 過去ログを取り込む

お使いだったサービスに応じて取り込み方法を選ぶ。

- **ChatGPT からの引っ越し**: ChatGPT の公式データエクスポート（`conversations.json` を含む ZIP）を用意し、`scripts/import_chatgpt_conversations.py` で取り込む。メモリーウィンドウの「引っ越し」タブからも同じ ZIP を取り込める。
- **Claude からの引っ越し**: 下の「[Claude からの引っ越し](#claude-からの引っ越し)」を参照。メモリーウィンドウの「引っ越し」タブ →「Claude 公式エクスポート」から取り込む。
- **SAIVerse 内の古い形式のログ**（旧バージョンの `log.json` 等）を再取り込みしたい場合: `scripts/import_persona_logs_to_saimemory.py` を使う。

どちらも、取り込みの際に呼ばれるのは「文章をデータベースに保存する」処理と「あとで検索できるように索引を作る」処理だけで、費用のかかる AI 呼び出しは一切行われない。

取り込みが終わると、完了報告が表示される。

```
============================================================
インポート完了: air_city_a
============================================================
挿入したメッセージ数:     3494
DB内の総メッセージ数:     3494
埋め込み済みメッセージ数: 3491 / 3491 (空メッセージを除く対象数)
所要時間:                 12.3 秒
------------------------------------------------------------
自動想起はこの時点から機能します。
Chronicle（あらすじ）の生成は任意で、後から scripts/build_arasuji.py
（費用見積もり付き、--estimate オプション）またはふだんの会話（Metabolism）
で少しずつ進みます。
============================================================
```

「埋め込み済みメッセージ数」が対象数と一致していれば、この時点で記憶は機能する状態になっている。

万が一、索引作りに使う小さな AI モデルが環境の都合で使えなかった場合は、その旨が案内される。その場合は環境を直してから同じコマンドをもう一度実行すれば、既に取り込んだ分だけ索引が作られる（重複して取り込まれることはない）。

### Claude からの引っ越し

Claude（claude.ai）の公式エクスポートは少し変わった配り方をする。

1. Claude の「設定 → プライバシー → データをエクスポート」を開き、期間を選んでエクスポートを実行する。
2. 受付メールの後、しばらくするとダウンロード用のメールが届く。
3. メールのリンクでダウンロードできるのは **manifest（JSON ファイル）だけ**。開くと中に複数の ZIP のダウンロード URL（`export_url`）が並んでいる。
4. 各 `export_url` から ZIP をダウンロードする。**リンクは 24 時間で失効し、一度開くと使えなくなることがある**ので、開いたらすぐ保存する。

ダウンロードした ZIP を、メモリーウィンドウ「引っ越し」タブ →「Claude 公式エクスポート」の対応する枠にドラッグ＆ドロップする。どの枠に入れるか迷っても、中身から自動判定して正しい枠を案内してくれる。

| ZIP | 取り込み先 |
|---|---|
| `conversations-*.zip` | 通常のチャット。会話を選んでスレッドとして取り込む |
| `claude_code_cloud-*.zip` | Claude Code のクラウドセッション。スレッドに再構成して取り込む（ツール実行だけの部分は除外） |
| `projects-*.zip` | プロジェクトの指示と資料をスレッドとして取り込む。指示はスレッド冒頭に system ロールで入り、希望すればペルソナのシステムプロンプトにも追記できる |
| `memories-*.zip` | Claude が蓄積した記憶。項目を選んで Memopedia（「Claude引っ越し」の下）に転記する |
| `frames-*.zip` | 生成された HTML 等の成果物のため **取り込み対象外** |

なお、Claude の設定画面にある「Claudeへの指示」（カスタム指示）は公式エクスポートに**含まれない**。ペルソナに引き継ぎたい場合は、ペルソナ設定のシステムプロンプトへ手で貼り付ける。

### 2. （任意）あらすじをまとめて作る

放っておいても、普段の会話のたびに少しずつあらすじが育っていく。「今すぐ人生の年表を通しで見たい」というときだけ、まとめて作る手動ツールを使う。

まず費用を見積もる（AI は呼ばれない、見積もりだけ）:

```bash
python scripts/build_arasuji.py <ペルソナID> --estimate
```

未処理のメッセージ数・何回 AI を呼ぶ必要があるか・概算の費用（対応モデルの場合）が表示される。表示だけで終了し、何も書き込まれない。

見積もりに納得したら、そのまま実行する:

```bash
python scripts/build_arasuji.py <ペルソナID>
```

（見積もりを表示したあと「実行しますか？」と確認される。確認をスキップしたい場合は `--yes` を付ける。)

## よくある質問

**Q. あらすじを作らないと何か困る？**
A. 直近の話題に関連する記憶（自動想起）はあらすじが無くても機能する。あらすじが無いと「ずっと昔からの人生の流れ」をペルソナが一望する力が弱くなる程度で、日々の会話への支障はほぼ無い。

**Q. 取り込みをやり直したらどうなる？**
A. 同じ内容を二重に取り込むと会話が重複するので、`--reset`（DBを作り直す）または `--append`（追記する）を明示的に選ぶ。詳細は各スクリプトの `--help` を参照。

**Q. 費用はどれくらい？**
A. 取り込み自体は無料（ローカルで完結する処理のみ）。あらすじ作りは使うモデルに応じて課金される場合があるが、実行前に必ず見積もりが表示されるので、金額を見てから判断できる。
