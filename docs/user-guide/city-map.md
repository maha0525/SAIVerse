# 街マップ（City Map）

City の Building を 2D 空間に配置して見渡すビュー。チャット領域ヘッダの「街マップ」ボタンで開く（`CityMap.tsx`）。

## 見方

- 各 Building は座標（`map_x` / `map_y`）に応じてセルとして配置される。セルには内装画像・説明・在室ペルソナのアバターが表示される
- **パン**（ドラッグで移動）と**ズーム**（0.3〜2.5倍）ができる
  - 拡大時（1.2倍以上）は**リッチ表示**（枠 + 内装画像 + 説明）
  - 縮小時は**ミニマル表示**（アイコン + ラベルのみ）
- 在室者はアバターで表示（最大6人、超過分は「他 N 人」）。無人の Building は「無人」と表示
- 一定間隔（約7秒）で在室状況を自動更新

## 操作

| 操作 | 結果 |
|---|---|
| Building をクリック | その Building を**閲覧**に切り替え（入室は発言時。→ [ワールドビュー](world-view.md)） |
| 在室ペルソナのアバターをクリック | ペルソナメニュー（ライフビュー / 記憶 / スケジュール / タスク / 設定 / 持ち物） |
| Region の入口 Building | その Region 内部のマップへ潜る |
| 「上の階層へ戻る」 | 親スコープのマップへ戻る |
| × または `Esc` | 街マップを閉じる |

## 編集モード

編集ボタン（配置を編集する）から:

- Building をドラッグして**マップ上の配置**を変更する
- マップの**背景画像**を設定 / 変更 / 削除する
