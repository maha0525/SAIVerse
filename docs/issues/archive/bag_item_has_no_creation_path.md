# Bag タイプのアイテムに作成経路がない

**起票**: 2026-09-01 (v0.3.0 リリース前の実機確認でまはーが発見)
**状態**: 完了 — まはー裁定「アイテム作成の一般経路として設計」を [room_item_display_cap.md](../../intent/room_item_display_cap.md) 設計 5 が引き取り、feature/room-item-cap で実装。右サイドバーの＋ボタンから Bag / Object を作成できることを 2026-09-13 まはーの実機で確認済み。あわせて、右サイドバーだけで完結する片付け経路 (かばんのまとめ収納・取り出し) も同ブランチで追加した

## 症状

Bag タイプのアイテムが実装されているのに、ユーザーがそれを作成する経路が
UI に存在しない。

## 方針 (2026-09-01 まはー)

Hotfix として UI からのアイテム作成機能を追加する。Bag に限らず
アイテム作成の一般経路として設計するのが自然。
