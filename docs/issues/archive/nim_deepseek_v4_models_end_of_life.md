# NIM の DeepSeek V4 の組み込みモデル 2 件が、提供終了で呼べなくなっている

**状態**: 完了 (2026-10-09) — 2 件を組み込みから外した (PR #380)。保留の理由だった「ほかにも止まっているものが無いか」は、同日に組み込みの全プロバイダを確かめて満たした (OpenRouter の 34 件は Nex N2.5 Pro (無料) 以外すべて生存、NIM は一覧と個別の問い合わせ、OpenAI は公式の提供終了の一覧と照合)。止まっていたのはこの 2 件と、OpenRouter の Nex (無料)、OpenAI の Chat 4 件で、まとめて外した。Gemma 4 31B の無応答はこの件とは別で、まはーの判断で NIM の推奨は現状のまま (NIM 自体が不安定なため判断しがたい)。
**深刻度**: P2 — この 2 件を選んでいるペルソナは、話しかけても返事が生まれない (選んだモデルが繋がらないときは代わりのモデルで動かさずに止まる、が v0.3.13 からの約束)

## 確認した事実 (2026-10-01、NIM の API に最小の一言を送って確かめた)

| モデル (同梱の定義) | NIM の返事 |
|---|---|
| DeepSeek V4 Pro 0813 (`builtin_data/models/nim-deepseek-v4-pro-0813.json`) | HTTP 410。「2026-09-14 08:00 UTC に end of life に達し、もう使えない」 |
| DeepSeek V4 Flash 0731 (`builtin_data/models/nim-deepseek-v4-flash-0731.json`) | HTTP 410。「2026-09-21 08:00 UTC に end of life に達し、もう使えない」 |

どちらも v0.3.12 (2026-09-11 発行) の棚卸しで組み込みに足したモデルで、足してから 3 日後と 10 日後に提供が終わっていた。

同じ日に確かめた NIM のほかの組み込みモデル:

- Muse Glimmer 30B: 応答あり (1 秒)。画像つきの構造化出力も通った ([nim_structured_output_drops_images.md](../nim_structured_output_drops_images.md) の経緯)。
- Nemotron 3 Ultra: 応答あり (6 秒)。
- Gemma 4 31B と Kimi K3: 90 秒待っても返事が無かった (提供終了の返事ではなく、無応答)。

## 決めること

- 2 件を組み込みカタログから外すか。外すなら、v0.3.12 のときと同じく「削除したモデルを選んでいた場合は選び直す」をリリースノートに書く約束が付く。
- 後継のモデルを足すか (NIM の一覧に後継があるかは未確認)。
- 「足してから数日で提供が終わる」ことを足す前に知る手段があるか (NIM のモデル一覧に終了予定日が載っているかは未確認)。
