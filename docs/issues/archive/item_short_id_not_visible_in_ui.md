# Issue: ペルソナが口にするアイテムの番号 (item:N) が UI のどこにも出ない

**ステータス**: ✅ 完了 — v0.3.16 で発行済み。2026-10-01 にまはーが実機のアイテム詳細で item:N の表示を確認した
**優先度**: medium (ユーザー報告。会話に出る番号を利用者が照合できない)
**作成日**: 2026-09-27
**報告**: an nin さん (Discord、2026-09-14)。「アイテムについてペルソナが話すときに数字を添えてくれるのですが、こちら側からその数字って見られるんでしょうか？」
**関連**: `saiverse/references.py` (短縮参照 `item:N`)、`manager/admin.py` (`get_item_details`)、`frontend/src/components/ItemModal.tsx`

## 症状

ペルソナはアイテムを `item:5` のような短縮参照で呼ぶが、この短縮参照が UI のどこにも表示されない。利用者は会話に出た数字がどのアイテムを指すのか照合できない。

## 原因 (コードで確認済み)

ペルソナに見えるのは世界で一意な短縮参照 `item:N` (N は `Item.SHORT_ID`、docs/intent/reference_addressing.md) で、UI のアイテム詳細モーダルに出ているのは内部の UUID (`ITEM_ID`) だけ。アイテム詳細 API (`get_item_details`) は `SHORT_ID` を返しておらず、フロントに出しようがない。

## 直す方向

1. `manager/admin.py` の `get_item_details` の返り値に `SHORT_ID` を足す。
2. アイテム詳細モーダル (`ItemModal.tsx`) のメタ情報の並びに、ペルソナが使う形そのままの `item:N` を表示する (UUID の表示は今のまま残す)。`SHORT_ID` は採番前の古い行で null になりうるので、そのときはこの表示を出さない。文言の追加は i18n の手順 (frontend/src/i18n/messages.json) に従う。
