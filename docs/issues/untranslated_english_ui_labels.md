**起票**: 2026-09-01 (v0.3.0 リリース前の実機確認でまはーが発見)
**状態**: 未解決 (低優先 — 「キリがない、後でいい」)

## 症状

日本語 UI の中に英語のままの箇所が散在する。確認済みの例:

- ヘッダーのツールチップ「Manage People」「Toggle Info Sidebar」

## 次の一手

一括で日本語化する。網羅が目的なので、個別に見つけ次第直すより
一度の掃討が向いている。
