# Issue: 自律行動 Track でペルソナの口調が崩れる

**ステータス**: 🔲 未着手 (低優先)
**優先度**: low
**作成日**: 2026-06-29
**関連**: `builtin_data/playbooks/public/track_autonomous.json` (action 末尾「発話は独白として自然に書いてください。」), `sea/head_pipeline/sections/autonomy_modes.py` (自律作業モード説明)

## 背景

自律行動 Track (自律作業モード) でペルソナが発話すると、メインモードでの口調・人格と比べて**口調が崩れる**事例がある。

## 仮説 (まはー)

`track_autonomous` の主ライン判断ノードの action 末尾にある「**発話は独白として自然に書いてください。**」のような指示が悪さをしている可能性。「独白」「自然に」という誘導が、ペルソナ本来の口調から離れた素の説明調・作業ログ調を引き出しているのではないか。

※ 未検証の仮説。実際の崩れたサンプルの収集と、プロンプト文言を変えた前後比較が必要。

## 直す方向 (案)

- 「独白として自然に」の文言を見直す。内的独白であっても**ペルソナの人格・口調は保つ**ことを明示する (例: 「あなたらしい言葉で」)。
- 自律作業モードでも persona_self / 人格セクションが head に効いているか確認 (軽量モデル + 自律ラインで人格プロンプトが薄まっていないか)。
- メインモードと自律モードで同一ペルソナの発話サンプルを並べ、どの要素 (モデル / プロンプト文言 / head セクション差) が口調差を生んでいるか切り分ける。
