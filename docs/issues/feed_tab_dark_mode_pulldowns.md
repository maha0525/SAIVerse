# フィードタブ「施設を追加」のプルダウンがダークモード非対応

**ステータス: 未解決** (2026-08-08 起票。時間割実機検証の Step 2 でまはーが発見)

## 症状

グローバル設定 → フィードタブ → 「施設を追加」で出てくる各種プルダウンが、全部ダークモードに対応できていない。

**深刻度: 見た目でなく操作不能** (2026-08-08 追記) — ダークモードだとプルダウンの候補が何も見えず、選択操作そのものができない。ダークモード利用者はライトモードへ切り替えないと施設を作れない。後回し棚の中では優先度高め。

## 背景

フィード管理 UI は 2026-08-02〜03 の夜間実装 (サブエージェント分業のエージェント B 担当)。memory の恒常規則「新規 UI はダークモード対応を同時に書く (毎回漏れる)」(feedback_darkmode_checklist) の再演。

## 直すときの範囲 (族で消す)

プルダウン (素の select) はダークモード漏れの定番。フィードタブだけ直して終わりにせず、**同ブランチで増えた新規 UI 面を一括で点検する**:

- フィードタブの全フォーム要素 (プルダウン以外の input / テキストエリアも)
- 習慣テンプレート編集モーダル (TimetableTemplateModal) のセレクト類
- ライフ設定モーダル (LifeSettingsModal)
- メモリーモーダル「経験」タブ

点検方法: ダークモードに切り替えて各画面を開く (resize_window の colorScheme か OS 設定)。CSS は既存のダークモード変数体系に乗せる。
