# Memopedia取り込みで壊れたコア記憶の救済

状態: **未着手**。正常化の対象。予防とは別の変更で扱う (2026-09-14 Astraレビュー)。

## 分かっていること

旧Memopedia exportはcore行の本文を含むがmetadataを運ばない。取り込みでできたmetadataの無い行が、コア記憶の一覧とheadの読み取りを落とす。合成データで再現済み。本番で影響を受けたペルソナがいるかは未確認。

正規の番号で削除しようとすると、取り込み先の別の記憶を指す場合がある。Memopediaの単体削除では壊れた行がごみ箱へ移り、ごみ箱の読み取りが落ちる。全削除を救済として案内しない。

## 次に具体化すること

- 読めない行を、読める行と区別して利用者へ示す方法と、対象を取り違えずに扱う経路。
- 本文・表題等の残存情報と、kind・confirmed・由来・正規ID等の失われた情報の区別。表題の番号を自動復元の根拠にしない。
- 正常な行・壊れた行・番号衝突・ごみ箱が混在した場合の検証。正常な本人の記憶や既存バックアップを変えない。
- headへの提示と会話の継続について、欠落を隠さず何を示せるか。既存の停止を無条件に正当化したり、黙って空にしたりしない。

まず壊す入口を塞ぎ、救済の適用をその後に行う。設計と合成データでの検証は、本番調査を待たずに進められる。本番への適用は対象と操作を特定して扱う。
