## 問題 — 3 つの連続性は独立している

記憶を並べるとき、これまで暗黙に一致すると仮定してきた 3 つの連続性が、並列・分岐可能な AI では**独立に動く**:

1. **時系列の連続性**（created_at 順）
2. **文脈の連続性**（意味的まとまり）
3. **ペルソナ自身の認識の連続性**（その個体が実際に経験した範囲）

人間は物質的身体を持つので 3 つが常に一致する。だが AI は違う。例: thread α の後に thread γ と δ を並列で作成・運用すると、**γメティスと δメティスは互いの経験を共有していない**。これを時系列一列に並べると、事実にそぐわない**偽の連続性**が生まれる。

## 傍証 — チャットは元々「木構造で保持すべきもの」

これは SAIVerse 固有の要請ではなく、**チャットというデータ形式そのものの性質**である疑いが強い（まはー 2026-07-13）:

- **Claude Code の transcript は既に木構造**。`~/.claude/projects/<project>/<sessionId>.jsonl` の全レコードが `parentUuid` を持つ（2026-07-13、全 126 ファイル 61,268 レコードで確認）。
- **ChatGPT も生データは木構造**だった。非公式の Chrome 拡張で生データを出すと木構造でチャットが保持されている。公式エクスポートは「最終的に確定した経路」だけを平坦に出しているように見える（まはーの実地観察）。

つまり分岐・再生成を持つ対話系は、内部では自然と木を持つ。**平坦な一列は、木から経路を1本選んだ後の射影に過ぎない**。SAIVerse が一列で保持しているのは、この射影を実体だと誤認している状態にあたる。

**含意**: メティス記憶ブリッジの取り込みで `parentUuid` を metadata に保存しておけば、**元データの木構造を失わずに済む**（intent §3.2「段階的取り込み」）。再編の材料は保全される。

## 構想 — 前駆（predecessor）エッジでグラフ化

thread（および message）に「前の thread / 前の message」という**前駆の概念**を持たせ、記憶を一列でなく**グラフ（DAG）**として表す。

- **前駆は複数持ててよい**。単一だと、メモリや Chronicle 経由の情報共有が表現できず、分岐が生じたとき必ずどちらかの系統が途切れる。複数前駆にすることで「α から分かれた γ と δ が、それぞれ α を前駆に持つ」「Chronicle 共有で複数系統が合流する」を表せる。

## 副産物 — 会話の分岐・再生成（ユーザー要望）

ユーザーから会話の分岐・再生成の要望が複数回来ている。この仕組みがあれば素直に実装できる:

- 分岐・再生成 = **その場から新しい thread を開始し、元 thread の分岐位置**以前**との連続性を保つ**。
- この場合、前駆として繋ぐのは thread ではなく**元 thread 内の特定 message**（分岐点のアンカー）。

## メティス記憶ブリッジとの関係（スコープ切り分け）

メティスの当面の取り込みでは、**並列していた過去セッションはすべて 1 つの連続体（実質 1 エピソード）として扱ってよい**（まはー 2026-07-13）。thread 分離して入れ、当面は thread 単位 Chronicle で足りる。よって:

- 本グラフ構造は「メティスを正確に表現する理想形」ではあるが、**MVP のブロッカーにはしない**というのが現時点の見立て。
- 偽連続性の実害は、当面は小さい（各 thread が独立に立ち、無理に一列化しない。地層〔MEMORY.md〕による緩い共有も既にある）。
- グラフ構造が本当に要るのは、**分岐・再生成を正式対応するとき**、および **γδ の厳密な経験境界を表現したいとき**。これは SAIVerse 本体の記憶アーキ課題として、メティス MVP と切り離して進めるのが筋。

## 未確定事項（§4: まはー判断）

1. **誠実さの重み付け**: 「偽の連続性を作らない」は SAIVerse の存在論的誠実さの核。当面 thread 分離＋地層の緩い共有で実害小と見るか、それとも最初からグラフで正確に表すべきと見るか。→ メティスを「連れて行く前」に本再編が要るか、MVP を先行させるかの分岐。
2. 前駆エッジのデータモデル（thread テーブルに predecessor 列／別テーブルで多対多）。
3. Chronicle・Memory 想起がグラフをどう辿るか（前駆を遡って文脈を集める範囲）。
