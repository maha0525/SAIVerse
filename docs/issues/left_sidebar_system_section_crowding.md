# Issue: 左サイドバーの「システム」欄が「場所」セクションを圧迫する

**ステータス**: 🔲 未着手
**優先度**: mid
**作成日**: 2026-07-08
**関連**: `frontend/src/components/Sidebar.tsx`

## 背景

左サイドバーの「システム」欄に並ぶ項目が増えてきて、**画面が小さめのユーザー**だと下部の「場所」セクション(Building 一覧など、日常操作の主役)が押し潰される。まはーの気づきから起票。

## 調査事項

1. `Sidebar.tsx` を読み、「システム」欄に現在どの項目が並んでいるか、「場所」セクションとの縦方向の領域配分(固定高 / flex / スクロール)がどうなっているか。
2. どの画面高で場所セクションが実用に耐えなくなるか(閾値)。
3. システム欄の各項目の利用頻度(常用 / たまに / 設定時のみ)。畳んでよいものの見極め。

## 解決案候補

- システム欄を**折りたたみ可能**にする、または低頻度項目をサブメニュー/オーバーフローメニューに畳む。
- 「場所」セクションに**最低高さ**を確保し、あふれ分はセクション内スクロールにする。
- システムと場所の縦配分を、場所優先に変える。

情報設計の判断(何を残し何を畳むか)が要るので、案を出して**まはーレビュー**にかける。
