# Issue: ライフビュー「いま」節の次パルス ETA が常に 0（last_pulse_at が誰にも書かれていない）

**ステータス**: 🔲 未着手
**優先度**: low
**作成日**: 2026-07-14
**関連**: `saiverse/activity_view.py` の `resolve_autonomous_pulse_interval` / `last_pulse_at` 参照

## 事実

ライフ v0.5 改修B（v1 亡霊の掃除、2026-07-14）の grep で発見: ライフビューの「いま」セクションが次パルスまでの残り時間（ETA）を `last_pulse_at` から計算しているが、**`last_pulse_at` を書き込むコードが saiverse/ のどこにも存在しない**。ETA は実質常に 0 表示。v1（SubLineScheduler の連続 Pulse）時代は書き手がいた可能性が高く、v2 移行で書き手だけが死んだ形。

## 方向（未決）

v2 の駆動は時間割・判断点ベースで「次パルスの ETA」という概念自体が変質している（次のコマの開始時刻ならライフビューの時間割表示で既に見える）。ETA 表示ごと退役させるのが素直だが、「いま」セクションの表示設計の一部なので、単純削除でなく表示の意味の再設計（次のコマ・次の判断点の予定を出す等）とセットで判断したい。ライフビュー関連の次の改修時についでに扱う。
