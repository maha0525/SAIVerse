# 自律行動を開始しても右サイドバーが「自律行動を止めています」のまま

**ステータス: 未解決** (2026-08-08 起票、時間割実機検証 Step 2〜3 の合間にまはーが発見)

## 症状

ライフ設定と習慣テンプレート保存のあと、**ライフビューから自律行動を開始**しても、右サイドバーには「自律行動を止めています」が表示され続けた。別の部屋を見て戻ってきたら表示は消えた — 状態そのものは正しく切り替わっており、**表示だけが古い** (再描画の契機がない)。

同日追記: **話しかけやすさチップ (活動中/休憩中) も同じ影響下**。チップの表示機能自体は生きているが、これも部屋の出入りで初めて現れた。右サイドバーの自律関連表示がまとめて同じ更新契機の欠落を踏んでいる可能性が高い。

## 見立て (未調査)

右サイドバーの自律状態表示が、自律行動の開始操作 (ライフビュー側) の成功を購読していない可能性がある。部屋の出入りで直るのは、部屋切り替えに伴う再取得で最新状態を読み直すため。開始操作の応答後に該当表示の再取得 (または開始操作側からの状態更新の伝搬) を入れれば済む見込み。

## 直す時期

実機検証の妨げにはならない軽度の表示遅延。検証一巡が終わってからで良い。ダークモード系 UI 修正 ([feed_tab_dark_mode_pulldowns.md](feed_tab_dark_mode_pulldowns.md)) と同じ束で拾うと効率が良い。
