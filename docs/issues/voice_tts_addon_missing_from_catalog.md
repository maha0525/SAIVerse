# Voice TTS アドオンがアドオンカタログに出てこない

**起票**: 2026-09-01 (v0.3.0 リリース前の実機確認でまはーが発見)
**状態**: 未解決 (v0.3.0 リリースはブロックしない — アドオン側の問題として切り離し)

## 症状

アドオンカタログ画面に Voice TTS アドオンが表示されず、UI からインストールできない。

## 次の一手

カタログの供給源 (カタログ JSON / 配布リポジトリ) に Voice TTS のエントリが
存在するかをまず確認する。エントリ自体が無いならカタログ登録の作業、
エントリがあるのに出ないならカタログ取得・フィルタ側の調査。
