# Issue: マップ画面アイコンクリック移動後、左サイドバーの現在地が更新されない

**ステータス**: 🔲 未着手
**優先度**: medium
**作成日**: 2026-05-09
**関連**: `frontend/` マップ画面, 左サイドバー現在地表示コンポーネント

## 背景

マップ画面で建物アイコンをクリックして移動した場合、移動自体は成功しているが、左サイドバーの「現在地」表示が更新されない。

通常のメニュー経由の移動では更新される (はず)。マップ経由のときだけ状態同期が抜けている可能性が高い。

## 確認事項

1. マップアイコンクリック時の移動処理が、現在地ステートを更新するイベント/Store を経由しているか
2. 通常移動とマップ移動で、現在地更新のフックが共通化されているか分離されているか

## 解決案候補

- 移動処理を共通フック化し、両経路で同じ Store 更新を呼ぶ
- マップ移動側の update 呼び出し漏れを修正 (局所修正)

判断: 「呼び出し忘れ」なら局所修正で十分。複数経路が独自に状態管理しているなら共通化検討。
