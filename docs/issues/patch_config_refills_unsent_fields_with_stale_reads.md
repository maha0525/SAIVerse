# PATCH /config が、送られていない欄を「先に読んだ現在値」で詰め直す

**ステータス**: 未解決 (段 3 のレビューで同族として発見。自律の欄だけ先に直した)
**起票**: 2026-10-12 (v0.4 段 3 の敵対レビュー 3 巡目の消し込み中、実装サブエージェントの報告)

## 現物

`api/routes/people/config.py` の PATCH ハンドラ (89〜106 行付近) は、リクエストに
無い欄 (説明・システムプロンプト・アバター・外見画像・名前・ホームの都市) を、
リクエスト処理の頭で読んだ現在値で埋めてから `update_ai` に渡す。

読みと保存の間に別の書き手 (世界エディタ・別のタブの設定画面) が同じ欄を変える
と、この PATCH が古い値で巻き戻す (read-modify-write の更新消失)。

## 経緯

同じ型の欠陥が **自律 ON/OFF (AUTONOMY_ENABLED)** にあり、全停止・停止ボタンを
巻き戻す実害 (課金の非常ブレーキが外れる) として 2026-10-12 の段 3 敵対レビュー
3 巡目が指摘した。自律の欄は UNSET (省略 = 触らない) を導入して閉じた
(コミット 99a18ac7)。モデルの欄は以前から UNSET 済み。残りの欄はこの issue。

## 直すとき

モデル・自律と同じ UNSET の形に揃える (省略 = 触らない)。フロントエンド
(SettingsModal) は読み込んだ値を常に送り返しているので、送る側も「変えた欄だけ
送る」に揃えるのが対。単一ユーザー運用では顕在化しにくく、優先度は低い。
