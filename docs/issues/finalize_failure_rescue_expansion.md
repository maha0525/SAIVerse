## 症状

ペルソナの発言を下書き行へ確定する処理が DB の混雑などで失敗すると、その発言が建物の記録に残らない。HEAD には、スペルの周の確定に失敗した本文を建物へ直接書き直す救済 (`sea/runtime_llm.py` の `_write_beat_body_directly`) が一箇所だけあるが、締めくくりの発言・普段の返事・中断時の確定には同種の救済が無い。

## 前実装が作った形 (参考 — 白紙化済み、差分は `C:\Users\shuhe\workspace\handoff_patches\2026-09-25_spell_stop_continue_wip.patch`)
