# Issue: フィードスタンド自体の削除と説明文の編集の口が無い

**ステータス**: 🟣 検証待ち
**優先度**: medium (ユーザー報告。回避は「購読を全部外して空のまま置く」しか無い)
**作成日**: 2026-09-29
**報告**: an nin さん (Discord、2026-09-28)。不具合報告4件のうちの④。
**関連**: `api/routes/feeds.py` / `saiverse/feed_manager.py::create_feed_fixture`

## 症状

フィードの追加・削除 (購読の付け外し) はできるが、フィードスタンドという設置物そのものを消す操作と、その説明文を編集する操作が UI にも API にも無い。報告者は不要になったスタンドの購読を外して空のまま置いている。

## 確認した事実 (2026-09-29)

`api/routes/feeds.py` の口は「施設の作成 / 一覧」「購読の追加 / 削除」「手動取得」「記事一覧」だけで、`DELETE /fixtures/{id}` と説明文 (DESCRIPTION) の更新の口が存在しない。汎用の設置物 API にも削除・編集の口は無い (`api/routes/` を横断確認)。作る口だけあって消す口が無い非対称。

## 直す方向 (未裁定)

施設の削除 API (購読・記事・既読カーソルの道連れ削除 — 削除まわりの並走対策は `remove_subscription` に前例がある) と、説明文の更新 API + UI。削除は「スタンドが部屋の様子とペルソナの知覚から消える」以上の波及を持たない想定だが、実装時に配送 worker との並走を確認する。

道連れ削除の対象には、2026-09-29 に足したスタンドごとの配信設定 (`feed_fixture_config` 表の同じ FIXTURE_ID の行) も含める。残すと、消したスタンドの設定行が孤児として残る (害は無いが、同じ ID のスタンドが将来作られた場合に古い設定を引き継ぐ)。

## 裁定 (2026-09-29 まはー)

設置物 (Fixture) はアイテムと同じ扱いにしたいので、削除の操作の形 (トンマナ) をアイテムとそろえる。調べた時点のアイテムは、部屋から開くモーダルに ⚙「メタ情報を編集」(名前・説明・配置場所) があるだけで削除が無く、削除は設定のワールドエディタにしか無かった。そこで両方を同じ形にそろえる:

- 設置物のモーダル (フィードスタンドを含む) にも ⚙「メタ情報を編集」を付け、名前と説明を編集できるようにする。
- 編集フォームに赤い「削除」ボタンを置く。アイテムにも設置物にも置く (まはー「アイテムもその場で削除できないのはちょっと不便だった」)。押すとワールドエディタと同じ確認を出す。
- ワールドエディタのアイテム削除はそのまま残す。
- 設置物を消すときは、ぶら下がっている記録 (観測の設定と観測値、フィードの購読・記事・既読の記録、配信設定) を同じ transaction で片付ける。
