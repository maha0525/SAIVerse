# 知覚バッファの出来事の区切りが見えない

**起票**: 2026-09-07 (まはーの実機所見 ③)
**状態**: 未着手 — 部屋の回収 ([room_state_packages.md](../intent/room_state_packages.md) §11) の実機検証後に形を決める

## 現象

未消費の知覚が複数の出来事にまたがって溜まると、消費時に一枚へ畳まれた文面の中で、どこからどこまでが一つの出来事なのか読み分けられない。まはーの実例 (アイフィの往復ダンプ) では、前の部屋の「役割・指示」と次の部屋の「様子 (前回見たときからの変化)」が見出しの並びだけで隣接し、並列の項目にしか見えなかった。

## 裁定済みの前提

- 移動の堆積そのものは §11 の回収が消す (移動由来の区切り問題の大半はそこで消える)。ただし**移動以外の出来事の間の区切りが見えない本質は残る** — まはーが ③ で明示。
- 区切りの印は**積むときにエントリ本文へ持たせる** — 提示時に後から足すと、提示済みブロックの描画が変わってキャッシュの前方一致が割れる (2026-09-07 メティス設計、まはー GO)。

## 次の一手

§11 の回収が入った後の実機ダンプを見て、残る区切り問題の実形から印の形 (罫線・時刻・出来事見出し等) を提案する。
