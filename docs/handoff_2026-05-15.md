## このセッションで踏んだ大きな失敗 (= memory 化推奨)

1. **「audio_completed = 再生完了」 と決めつけて報告した** (= 経験的にイベント名から推測しただけで根拠ゼロ)。 まはー が「コード上の根拠を示してほしい」 と詰めた時点で wav saved log の audio_duration を確認すれば一発で気づけた。 *Memory*: 「イベント名で意味を推測しない、 実装読むかログで実証する」
2. **DEBUG ログ十分なのに WARNING で出した** (= 「念のため目立たせる」 という雑な根拠)。 まはー の指摘で訂正。 *Memory*: 「SAIVERSE_LOG_LEVEL=DEBUG なら DEBUG はファイルに出る、 WARNING に上げる必要ない」
3. **「voice-tts は strict FIFO」 と過信** (= playback_worker のコード構造だけで判断、 sounddevice の挙動まで実装読まずに断定)。 観測ログで audio_duration > total elapsed なのを見れば矛盾に気づけた
