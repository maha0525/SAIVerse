# Install this AFTER requirements.lock:
#   pip install -r requirements.lock
#   pip install -r requirements-gpu.txt
#

#   - NVIDIA GPU with CUDA support
#   - CUDA Toolkit 12.x installed
#   - cuDNN 9.x installed
#
# See docs/getting-started/gpu-setup.md for detailed instructions.
#
# The SAIMemory embeddings run on CPU only (docs/intent/embedding_gemma2_migration.md),
# so onnxruntime-gpu is no longer needed (the CPU onnxruntime from the lock is used).
